# NAM · GitHub Pages

Compact English sister site for notanothermate.com. Static HTML, CSS and a small script for the copyright year; no build step or external font/CDN dependencies.

## Local preview

`python3 -m http.server 8082 --bind 127.0.0.1`

Open http://127.0.0.1:8082/ .

Uses the approved October 2026 logo, local Geist fonts, studio composition, team portraits and watercolour product artwork. MiniMate is intentionally omitted. Contact opens the visitor's email application with the recipient and subject prepared.

## Publishing

GitHub Pages serves the approved site from the main branch. Legal and services links point to the corresponding pages on the main NAM website.
